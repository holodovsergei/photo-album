# photo-album
photo-album карусель для Notion. Задний фон (Сетка фотографий): Изображения из списка выстраиваются на заднем плане в виде сетки (например, 2 ряда по 4 фотографии). Они будут заполнять весь задний план экрана. 
Передний план (Карусель): Поверх этой фоновой мозаики, ровно по центру, будет располагаться активная карусель.
Взаимодействие: При нажатии на стрелочки, центральная (яркая) фотография перелистывается, а фоновая сетка из всех фотографий остается неподвижной как стильная подложка.
Как заменить фото? Удалить ссылку-заглушку внутри кавычек src="..." файла index.html и вставить туда прямую ссылку на нужное фото (которое загружено, например, в VK, на хостинг картинок или в Google Drive с открытым доступом)
